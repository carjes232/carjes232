## Selected work

- **Quiver — document workflows:** lead architecture, qualification and release acceptance for a collaboratively developed Teams assistant producing editable SOPs, flowcharts and presentations. Focus on source provenance, requester isolation, revision recovery and consent-aware delivery.
- **SST — production voice reliability:** improve evaluation and recovery in an inherited Spanish-language voice platform. A retrospective found about **70% lower mean recorded cost among costed calls** after voicemail-related improvements; missing billing and different cohorts prevent treating that as causal realized savings. A separate **80.7% input-token reduction** covers 12 matched synthetic development cases, not production voice bills.
- **Solenium — edge ML and computer vision:** led the ML component of a smart-meter disaggregation system and developed field-attendance vision with offline handling. Work connects inference, device telemetry and recovery.
- **Magnus — full-time ML Engineer (May 2023–July 2024):** contributed Azure OpenAI integrations, prompt testing and RAG retrieval for clinical-training and survey-feedback applications.
- **Backend and systems:** build auditable reconciliation and API workflows; direct agent-assisted browser controls and Linux reliability improvements. Emphasize idempotency, bounded queues, explicit authority and reconciliation of uncertain outcomes.

Company repositories and private data stay private. [Sanitized case studies](https://danielcardenas.dev/projects) distinguish my contribution, shipped work, prototypes and measurement limits.
